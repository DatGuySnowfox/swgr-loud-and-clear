1.2.0

New: an in-game mix panel on HOME. Nine sliders, voice level and the seven channels competing with it, each with a live dB readout. Drag with the mouse and you hear every change while you make it.
New: Save, Undo, Mod defaults, and a Compare toggle that switches between your mix and the game's own, playing a sample through every channel so there is something to judge by ear.
New: your settings are saved and reloaded on the next launch, so tuning no longer means editing the Lua by hand.
New: an optional cutscene guard that keeps the panel shut while a cutscene plays. Off by default, because this game runs ambient idle animations through the same system and the guard cannot tell the two apart, so it blocked the panel in hub areas. Set cutscene_guard = true in CONFIG if you want it.
New: Ctrl+F10 and the lac_cutscene command report whether a cutscene is currently detected, and Ctrl+END lists which sound classes and assets the loaded sounds use.
Fixed: dialogue could end up louder than you set it. Under some reload conditions the mod read its own boosted output back as the game's original level and boosted it again, compounding each time. It now refuses to record a value that is not the authored one, and says so in the log.
Fixed: the mod no longer scans the whole audio graph on every launch. That was several hundred object lookups at startup for information that is now written down.
Compatible with the 8 October game patch, build 25801363, which moved two of the addresses UE4SS uses to find the engine. If UE4SS started crashing for you after that patch, replacement signature files are in the GitHub repo under Signatures/.
Changed: the download no longer bundles the UE4SS signature files. They are UE4SS configuration rather than mod files, and shipping them invited overwriting a working setup that never needed touching. They are in the repo for anyone who needs them.

1.0.0

Initial release. Boosts the dialogue sound classes to 1.7x and ducks music, crowds, airflow, engines and ambience by 1.9 to 4.4 dB.
